Drive Notes

Alt + right-click a Drive file or folder to edit its description.

Behaviour

Held while right-clicking. Drive draws its own context menu, so a plain right-click can't be extended, so the modifier is what lets us take over.

The existing description always loads into the box with the cursor at the very end, ready to type. This only controls what gets pre-typed for you first: nothing, a line break, or a blank line plus today's date.

Plan

Google account

Nothing to set up. Each Google account is authorized on its own, the first time you edit a description in one of its Drive tabs, and appears here once it has been. If you're signed into several accounts, the extension follows whichever one the tab belongs to.

The first time in each account, Google shows a “Google hasn’t verified this app” screen. That’s expected: this extension talks to your Drive directly from your browser and hasn’t been through Google’s paid verification review. Choose Advanced → Go to File Notes to continue.

    Disconnecting forgets an account here. To withdraw the access grant itself, use your Google account permissions page.

    Advanced: use your own OAuth client
